# PythonPractice_for_DSTU
Консольная программа на Python для анализа чисел (чётность, простота, полный квадрат и др.) — практические работы 1-2

# Проверка характеристик числа

## Назначение проекта
Консольная программа анализирует введённые пользователем целые числа и выводит
набор их характеристик. Поддерживает последовательный анализ нескольких чисел
за один запуск.

## Задачи, которые решает программа
- Определяет, положительное число, отрицательное или ноль
- Определяет чётность числа
- Проверяет делимость на 3 и на 5
- Проверяет, является ли число простым
- Считает количество цифр в числе
- Проверяет, является ли число полным квадратом целого числа
- Обрабатывает случай, когда введено не целое число
- Позволяет проверить несколько чисел подряд без перезапуска программы

## Инструкция по запуску
1. Убедитесь, что установлен Python 3.
2. Запустите файл командой:
   ```
   python 3.py
   ```

## Как пользоваться программой
1. Введите целое число (положительное, отрицательное или ноль).
2. Программа выведет все характеристики числа, включая проверку на полный квадрат.
3. Если введено не число, программа сообщит об ошибке и спросит, хотите ли вы
   проверить ещё одно число.
4. На вопрос "Проверить ещё одно число?" ответьте "да", чтобы продолжить, или
   любым другим текстом, чтобы завершить работу программы.

## Пример работы

```
Введите число: 17

```
