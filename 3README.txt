# Проверка характеристик числа

## Назначение проекта
Консольная программа анализирует введённое пользователем целое число и выводит
набор его характеристик.

## Задачи, которые решает программа
- Определяет, положительное число, отрицательное или ноль
- Определяет чётность числа
- Проверяет делимость на 3 и на 5
- Проверяет, является ли число простым
- Считает количество цифр в числе
- Обрабатывает случай, когда введено не целое число

## Инструкция по запуску
1. Убедитесь, что установлен Python 3.
2. Запустите файл командой:
   ```
   python 3.py
   ```

## Как пользоваться программой
1. Введите целое число (положительное, отрицательное или ноль).
2. Программа выведет все характеристики числа.
3. Если введено не число, программа сообщит об ошибке.

## Пример работы
```
Введите число: 13
Ваше число: 13
Положительное: да
Четное: нет
Делится на 3: нет
Делится на 5: нет
Простое: да
Количество цифр: 2
```
